# Claude Elite Content Agency

Sistema de agencia de contenido para Instagram dentro de Claude Code.

- Coordinador: [`CLAUDE_CONTENT_AGENCY.md`](CLAUDE_CONTENT_AGENCY.md) (importado desde `/CLAUDE.md`)
- Skills: [`/.claude/skills/`](../.claude/skills/) — 10 especialistas
- Documentación: [`docs/`](docs/) (01–08)
- Pruebas: [`tests/`](tests/) (A–E; F–H en `docs/07`)
- Automatización: [`automation/`](automation/) — plantilla n8n inactiva + validador de Skills
- Entregables por marca: `clientes/<marca>/`
- Respaldo de configuración: [`backups/`](backups/)

Inicio rápido: abre Claude Code en este repo y escribe *"Nueva marca: [qué vendes, dónde, objetivo]. Haz el brief estratégico."*
